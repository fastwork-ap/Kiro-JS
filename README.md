# Kiro-JS

A collection of JavaScript utilities.

## Contents

- `set-color-from-state.js` — Nintex form custom JavaScript that sets a Single
  Line of Text field based on a dropdown choice (e.g. selecting **Georgia**
  sets the text field to **Red**).

## Notes

`set-color-from-state.js` uses `NWF$` (Nintex's bundled jQuery) and is meant to
run inside a Nintex form in the browser, not standalone under Node.js.
